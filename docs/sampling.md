# 分层抽查清单（sampling）

对拍与复核的必查样本，按风险层抽取：

1. **子正边界**：每年取 2 个日期，验证 0:00-1:00 换日行为（自研 0:00 子正 vs oracle 23:00 子初差异单列）。
2. **节气 ±2h**：对已录入节气数据，取每季 1 个节气时刻 ±2 小时窗口内日期，验 month/term 归属。
3. **闰月**：1900-2100 内每个闰年取闰月当月朔日，验证朔望与闰月归属。
4. **1900 前后**：1900-01-01 前后各 30 天、1899-12-31 与 1900-01-01 交界，验证儒略历/格里高利历声明生效。
5. **2100 边界**：2100-12-31 收尾与 2101-01-01 越界拒绝行为。
6. **1500 年前古代段**：1500 年前区间（儒略历声明区）每 100 年取 1 个采样点，验证时辰级精度与历法归属，差异入仲裁。
7. **甲子/甲午类整轮日**：60 甲子循环边界日（如甲子日、癸亥日次日），验证 mod 60 无漂移。

抽查结果记录于 compare_report.txt 与 arbitration_log.csv；命中差异一律进入仲裁流程，不静默修正。

## 执行主体

抽查与复核由独立审计者执行（非实现者）；实现者只提供数据、对拍日志与仲裁所需证据，不参与样本抽取与判定。

## 哈希冻结机制

抽查通过后冻结：生成 SHA256SUMS.txt 清单（覆盖 data/docs/report/代码全量文件），首行记录生成时间（ISO8601）；校验命令 `sha256sum -c SHA256SUMS.txt`（Windows 单文件：`certutil -hashfile <file> SHA256`）。冻结后再变更须走勘误通道（见 preregister.md 勘误补丁通道），不得静默改动。
