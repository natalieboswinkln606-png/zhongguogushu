   - 歌诀中天干所化星曜严格对应“禄、权、科、忌”四序。
   - **“庚日武同阴”**：日（太阳化禄）、武（武曲化权）、同（**天同化科**）、阴（**太阴化忌**）。

## 三、冲突点 2：紫微闰月起盘处理与古历源流裁决

### 3.1 事实认定与代码证据
- **外部开源库事实**：
  - `iztro` 源码（`src/astro/palace.ts` L52-62）默认启用 `fixLeap: true`：
    ```typescript
    const needToAdd = isLeap && fixLeap && lunarDay > 15 && timeIndex !== 12;
    return fixIndex(lunarMonth + 1 - firstIndex + (needToAdd ? 1 : 0));
    ```
    即：**15 日月中分界**（初一至十五算本月，十六日起算次月）。
  - `HeiGe-SuanMing` 同轨支持此行为。
- **`D:\shushu` 事实**：
  - `l3_ziwei.py` 第 102 行强制写死：
    ```python
    qi_mo = lmo + (1 if lruen else 0)
    ```
    即：只要是闰月，**一律按次月顺延排盘**（例如闰二月初一直接按三月起命宫）。

### 3.2 古代星历与明清文献考证
关于紫微斗数如何处理闰月，历史文献主要存在四大流派：
1. **月中分界法（半月中分派）**：
   - **文献出处**：明刻本《紫微斗数全书》卷一《定闰月捷法》：
     > “闰月生人作何安命？……假如闰三月初一至十五日，仍作三月安命；十六日以后，作四月安命。”
   - **地位**：这是明清两代官方与坊间刊印本中**唯一有明文口诀支撑的传统古法**，流传最广，为港台各派（三合派、占验派）及 `iztro` 所遵奉。
2. **闰月归次月法（顺延进位派）**：
   - **源流**：多见于近代北方盲派及现代部分排盘商业站点（如易安居 zhouyi.cc），认为闰月既然是由于阴历追赶阳历中气所生，其气已衰，应直接视作下一正气。
3. **闰月归本月法（不重闰派）**：
   - **源流**：台湾部分学者认为紫微安星系以干支太岁与月建为机，闰月仍属该月建之延伸，故整月皆依本月排盘。`iztro` 设 `fixLeap: false` 即为此派。
4. **节气定月建派（天星化斗数派）**：
   - 完全抛弃阴历朔望月，直接以太阳过黄经 15 度交节换月（与四柱八字完全同轨）。

### 3.3 裁决与责任认定
- **裁决：shushu 存在单一 Oracle 耦合的功能局限（Functional Limitation）**。
  - 虽然 `shushu` 在代码注释中记录了“对拍易安居实测”，但易安居本身是一个商业黑盒网站。
  - 明刻《紫微斗数全书》原典确凿无误地记载了“十五日月中分界法”。`shushu` 在底层直接写死 `lmo + 1`，导致闰月前半月（初一至十五）生人的命宫、身宫、左辅、右弼发生整整 **1 个宫位的系统性位移**！
  - 这种“为了迎合易安居单点用例而放弃古籍大宗法则”的做法，属于**功能不全与过拟合缺陷**。

### 3.4 对 shushu 的纠偏或升级指令
- **升级改造方案**：
  在 `l3_ziwei.py` 与 `config_engine.py` 中引入 `leap_month_mode` 配置枚举：
  1. `"mid_month_cutoff"`（**古籍全书默认**：`day <= 15 ? lmo : lmo + 1`）；
  2. `"next_month"`（**易安居 oracle 兼容**：`lmo + 1`，即现有逻辑）；
  3. `"current_month"`（**归本月派**：`lmo`）。
  保持向后兼容的同时，将古籍通行的 15 日月中分界法纳入正规军。

### 5.2 历史源流、吴语谐音讹传考证与清廷钦定平反
1. **明代古本与钦定辨伪**：
   - 《渊海子平》卷二《天乙贵人》原文：
     > “甲戊兼牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，庚辛逢马虎，此是贵人方。”
   - 清代乾隆帝敕命大学士嵇璜、纪昀等编纂的皇家级天文数理权威巨著《协纪辨方书》（卷三·义例一）对此作出了盖棺定论的学术辨伪：
     > **“古歌：‘甲戊兼牛羊，庚辛逢马虎。’‘兼’字后人误作‘庚’，因改‘庚辛’为‘六辛’，非也！盖金生于巳，旺于酉，墓于丑，长生、旺、墓乃三合之象，庚辛之贵在午寅，火克金也，亦水火交济之理。”**
   - **语言学考据**：明代江南书坊多在吴方言区，“兼”（jiān / kian）与“庚”（gēng / kang）入声互通声母相近，传抄刻工望音生义，将“兼”刻为“庚”！为了凑齐十干，又将下一句“庚辛逢马虎”剜改成“六辛逢马虎”！这一文字学讹误被清代民国坊间医卜星相之徒沿用至今。
2. **五行偶对与群论对称性数学证明**：
   - 天干十数在群论下构成模 10 的加法群。天干配贵人严格按“阴阳配偶、水火互济”成双配对：
